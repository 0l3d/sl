Adds a socket file descriptor to the specified fd_set.

Resolves a domain name (hostname string) into an IPv4 address string.

Sets the specified socket to non-blocking mode.

Sets options on the specified socket. Returns true on success.

Sends a string of data over a connected socket.

Initiates a connection on a socket to a specified address. (See DIFFERENCES for overloads).

Closes the specified socket file descriptor.

-- USAGE OF ALL FUNCTIONS --
use("net")

# Resolve hostname
var ip = net.resolve("example.com")

# Create a socket using integer constants
var server_sock = net.new_socket($AF_INET, $SOCK_STREAM, $IPPROTO_IP)

# Set socket options and non-blocking mode
net.setsockopt($server_sock, $SOL_SOCKET, $SO_REUSEADDR, 1)
net.set_nonblocking($server_sock)

# Bind and Listen (Basic Mode)
net.bind($server_sock, "127.0.0.1", 8080)
net.listen($server_sock, $SOMAXCONN)

# File descriptor sets for multiplexing
var read_fd = net.new_fd()
var write_fd = net.new_fd()
var except_fd = net.new_fd()

# Manage FD sets
net.zero_fd($read_fd)
net.add_fd($server_sock, $read_fd)

# Check and remove FD from a set
var is_set = net.check_fd($server_sock, $read_fd)
net.remove_fd($server_sock, $read_fd)
net.add_fd($server_sock, $read_fd) # Adding back for select

# Select operation (Wait up to 5000ms)
var active = net.select($server_sock + 1, $read_fd, $write_fd, $except_fd, 5000)

# Accept client connection
var client_sock = net.accept($server_sock)

# Receive data from client
var data = net.recv($client_sock, 1024, 0)

# Send data back to client
net.send($client_sock, "HTTP/1.1 200 OK\r\n\r\n", 0)

# Connect as a client (Basic Mode)
var out_sock = net.new_socket($AF_INET, $SOCK_STREAM, $IPPROTO_TCP)
net.connect($out_sock, $ip, 80)

# Clean up resources
net.close($client_sock)
net.close($server_sock)
net.close($out_sock)

-- DIFFERENCES --
Differences in basic and complex modes for net.connect and net.bind:
Both functions support argument-based overloading depending on the total arguments provided (3 vs 4).

* Basic Mode (3 arguments):
  + Usage: net.bind(sockfd, ip_string, port_integer)
  + Usage: net.connect(sockfd, ip_string, port_integer)
  + Description: Takes a string representation of an IP address and an integer port. The address family is automatically set to AF_INET internally.

* Complex Mode (4 arguments):
  + Usage: net.bind(sockfd, family_integer, addr_integer, port_integer)
  + Usage: net.connect(sockfd, family_integer, addr_integer, port_integer)
  + Description: Takes integers for the address family, raw address bytes (s_addr), and the port. Required for advanced socket configurations.

++ NOTES
WinAPI and POSIX API are implemented as the exact same API in this language. There is absolutely no usage difference in the language scope between operating systems.

This is a low-level socket API. It provides the most fundamental network access required by the operating system. It is NOT an HTTP, HTTPS, or high-level networking library implementation.

Overloading in dyn.set_field based on argument count:

* Standard Mode (3 arguments):
  + Usage: dyn.set_field(struct_ptr, offset, value)
  + Description: Writes the value directly into memory using its inferred native type.

* Explicit Type Mode (4 arguments):
  + Usage: dyn.set_field(struct_ptr, offset, type, value)
  + Description: Takes an explicit type constant (e.g., $DYN_TYPE_INT) to cast the value before writing it to the struct buffer.

-- INCLUDING --
use("collections")

-- FUNCTIONS --
Collections.create_collection -> name, [field/method_specs...] | VOID
Registers a custom collection (object-like system) with defined attributes and methods. 
Automatically creates a constructor function named "<CollectionName>:new".

Collections.get_attr -> instance, attr_name | VAR
Retrieves value of internal attribute from collection instance.

Collections.set_attr -> instance, attr_name, val | VOID
Sets value of internal attribute in collection instance.

-- USAGE OF ALL FUNCTIONS --
use("collections")
# use("list")

# Define method for collection
def Custom_add -> key then
    var key_list = Collections.get_attr($self, "keys")
    List.push($key_list, $key)
end

# Create collection definition
Collections.create_collection("Custom",
    "v:keys",
    "f:Custom_add:add"
)

# Instantiate new object via constructor
var mymap = Custom:new()
# Get/Set attr
$mymap.keys = List.new()
# Call method on collection
mymap:add("hello")

++ NOTES
- Attributes are registered with the prefix "v:" (e.g. "v:keys").
- Methods/Functions are registered with the prefix "f:" formatted as "f:orig_func_name:method_name" (e.g. "f:Custom_add:add").
- Calling Collections.create_collection automatically generates a constructor function named "<CollectionName>:new" (e.g. "Custom:new").
- When an instance is created, attributes are stored in memory as "instance.attr_name" and methods as "instance:method_name".
- Inside collection methods, the variable "self" automatically refers to the instance name.
